# AUTOMATIC-SPEECH-RECOGNITION-SYSTEM
# 🎙️ Automatic Speech Recognition System Using Whisper

## 📌 Overview

The **Automatic Speech Recognition (ASR) System** is an AI-based application that converts human speech into written text. The system uses the **Whisper speech recognition model** to process audio and accurately identify spoken words.

The application provides a simple **Gradio web interface** where users can upload an audio file or record speech using a microphone and convert it into text.

## 🎯 Objectives

* To convert speech into text automatically.
* To understand the basic concepts of Speech Recognition.
* To use an AI-based speech recognition model.
* To provide an easy-to-use web interface.
* To develop and run the application in Google Colab.

## 🛠️ Technologies Used

* **Python**
* **OpenAI Whisper**
* **Gradio**
* **Artificial Intelligence**
* **Speech Processing**
* **Google Colab**

## ⚙️ How It Works

1. The user uploads an audio file or records speech using a microphone.
2. The audio is provided to the Whisper model.
3. Whisper analyzes the speech signal.
4. The spoken words are converted into text.
5. The recognized text is displayed on the Gradio interface.

## ✨ Features

* 🎤 Microphone recording
* 📁 Audio file upload
* 🤖 AI-powered speech recognition
* 📝 Automatic speech-to-text conversion
* 🌐 Interactive Gradio interface
* ☁️ Google Colab support

## ▶️ How to Run

### Step 1: Open Google Colab

Create a new notebook in Google Colab.

### Step 2: Add the Code

Copy the complete ASR Python code into a single cell.

### Step 3: Run the Code

Click the **Run ▶** button and wait for the required libraries and Whisper model to load.

### Step 4: Open the Application

After execution, Gradio will generate a link. Open the link to access the ASR application.

### Step 5: Convert Speech

Upload an audio file or record speech using the microphone and click:

**🔊 Convert Speech to Text**
